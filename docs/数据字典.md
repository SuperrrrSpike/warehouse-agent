# 数据字典

## 1. 原始文件

| 文件 | 粒度 | 关键字段 | 用途 |
|---|---|---|---|
| `Picking_Wave.csv` | 拣选明细 | `waveNumber`, `reference`, `locations`, `quantityToPick (units)`, `operator` | 计算波次规模、商品/库位分布和拣选顺序 |
| `Customer_Order.csv` | 客户订单 | `waveNumber`, `orderNumber`, `codCustomer`, `creationDate`, `quantity (units)` | 补充订单数、客户数、订单时间和订购数量 |
| `Storage_Location.csv` | 库位 | `originalLocation`, `x`, `y`, `z` | 将库位编码映射为仓库空间坐标 |
| `Product.csv` | 商品主数据 | `Reference`, `ABCCOD`, `Sector` | 补充 ABC 分类和商品分区 |

原始数据来自 [Mendeley Data 数据集](https://data.mendeley.com/datasets/pf2w725pw3/1)，下载脚本会记录来源文件的 SHA-256。`Picking_Wave.csv` 中的重复行按来源定义视为单位级拣选事件，不直接删除。

## 2. 波次级特征

### 规模与结构

- `pick_lines`：拣选明细行数。
- `total_units`：波次拣选数量合计。
- `unique_skus`：不同商品数。
- `unique_locations`：不同库位数。
- `order_count` / `customer_count` / `ordered_units`：关联订单统计。
- `abc_a_share`：A 类商品在明细中的比例。

### 空间与质量

- `mapped_pick_count`：成功映射到坐标的明细数。
- `mapping_rate`：库位坐标映射率。
- `product_mapping_rate`：商品主数据映射率。
- `aisle_count`：出现过的巷道首字符数量。
- `floor_count`：出现过的楼层数量。
- `x_mean` / `y_mean`：拣选点空间均值。
- `x_std` / `y_std`：拣选点空间离散程度。
- `x_range` / `y_range`：空间跨度。
- `weekday` / `month`：波次创建日期特征。

### 标签与训练门槛

- `route_distance_proxy`：从固定 depot `(66,-29)` 出发，按源文件拣选顺序经过有效坐标并返回 depot 的曼哈顿距离代理值。
- `eligible_for_training`：创建时间有效、映射率至少 80%、有效坐标点至少 3 个且目标大于 0 时为真。

## 3. 模型输出

- `predicted_route_distance`：模型预测的路线负荷代理值。
- `prediction_lower_p90` / `prediction_upper_p90`：预测值减/加验证集绝对误差 90 分位，供容量复核使用。
- `workload_band`：按预测值 P50/P75/P90 分成 `normal`、`elevated`、`high`、`critical`。
- `recommended_action`：透明规则生成的人工复核建议，不是自动调度指令。
- `model_version` / `scored_at`：模型版本和评分时间。

## 4. 当前数据质量口径

训练只使用 `eligible_for_training=true` 的波次；所有波次仍保留在 `wave_features.csv` 供审计。库位缺失、商品缺失、日期缺失和原始重复记录会写入 `data_quality_report.json`，不会静默丢弃。
